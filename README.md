# Canvas Visibility Spoofer

**Description:**

Canvas Visibility Spoofer is an extension to spoof when you switch tabs. This intercepts and injects inself into the Canvas Webpage to make it look like you never switched. Based on my testing, it successfully blocks Alt + Tab, Mouse Pointer going in and out and more. Please test and give feedback

> ⭐ How can I contribute?
Please test it on a Canvas quiz (without any proctoring software) and report back by creating a new topic in "Issues" page of the GitHub. This allows me to track the success rate and to make any improvements. I unfortunately do not have a Canvas Lite account, so I cannot test myself. However, testing on https://focus-on-me-now.lovable.app shows that it is successfully blocked.

> ❓ How can i download it?
Head to the Releases tab and download the folder. Unzip it and go to chrome://extensions, then click the extension toggle switch titled Developer Mode. 3 new buttons on the left will appear, click Load unpacked and select the unzipped extension folder
